# Prototipos de diseño

Exploración visual previa al rediseño v5. **No se despliega** (está fuera de `public/`).

| Archivo | Qué es |
|---|---|
| `prototipos/index.html` | Hub: las tres direcciones (A Letrero, B Neón, C Andén), paletas y visor de resoluciones |
| `prototipos/a-v1.html` → `a-v3.html` | Iteraciones de la dirección elegida (A); **v3 = base del sitio** |
| `prototipos/comparar.html` | Comparador lado a lado entre versiones |
| `prototipos/versions.js` | Registro de versiones y changelog del dock |

Para verlos en local:

```bash
npx serve design/prototipos
```
